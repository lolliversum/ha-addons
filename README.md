# Lolliversum Home-Assistant-Add-ons

Öffentlich, weil Home Assistant Add-ons nur so ohne Zugangsdaten in der Adresse lädt.
Hier liegt **nur Programmcode** – keine Schlüssel, keine Kundendaten, keine Einstellungen.
Die Einstellungen je Standort (gut, leon, kiel) liegen im privaten Repo lolliversum/smarthome.

- **Lolliversum Druckbrücke** – holt Druckaufträge vom Lolliversum-Portal, gibt sie an Drucker im lokalen Netz.
- **Lolliversum Sync** – holt den Ordner des eigenen Standorts aus dem privaten Repo (Schlüssel im Add-on, nie im Protokoll).
